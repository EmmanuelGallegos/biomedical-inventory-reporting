# Public release rules

Only independently generated fictional inventories and their outputs may be published.

Do not publish company or customer names, original unit maps, serial numbers, asset IDs, locations, actual quantities, acquisition prices, logos, original report templates, credentials, local paths, or notebook outputs derived from real inputs.

Renaming or translating real labels does not make original records synthetic.

The demo uses generic input headers and fictional unit names, brands, models, and records. V2 useful-life fields stay blank: no real reference table or invented useful-life assumptions are published.

Confirm permission before applying a software license to workplace-derived source code. No blanket license is assigned in this initial repository.
